Overview

The PingPilot API is a read-only REST API that lets you retrieve your monitor data. All requests return JSON and require authentication via an API key.

Base URL: {{ site_url }}/api/

Authentication

Every request must include your API key in the X-API-Key header:

curl -H "X-API-Key: pp_YOUR_KEY_HERE" {{ site_url }}/api/monitors/

Keys are managed from the API Keys page. You can create multiple named keys and revoke them individually.

List Monitors GET

Returns all monitors for your account.

GET /api/monitors/
Example Request
curl -H "X-API-Key: pp_..." {{ site_url }}/api/monitors/
Example Response
[
  {
    "id": 1,
    "name": "My Website",
    "url": "https://example.com",
    "method": "GET",
    "expected_status": 200,
    "check_interval_seconds": 60,
    "last_status": "UP",
    "last_checked_at": "2026-07-30T12:00:00Z",
    "is_active": true,
    "created_at": "2026-01-15T08:30:00Z"
  }
]
Response Fields
FieldTypeDescription
idintUnique monitor ID
namestringMonitor display name
urlstringTarget URL being monitored
methodstringHTTP method (GET, POST, etc.)
expected_statusintExpected HTTP status code
check_interval_secondsintCheck interval in seconds
last_statusstringUP, DOWN, DEGRADED, or null
last_checked_atdatetimeLast check timestamp (ISO 8601)
is_activeboolWhether monitoring is active
created_atdatetimeCreation timestamp

Heartbeat Log GET

Returns the heartbeat (check) log for a monitor. Ordered by most recent first, limited to 100 entries.

GET /api/monitors/<id>/heartbeats/
GET /api/monitors/<id>/heartbeats/?days=7
Query Parameters
ParameterTypeDefaultDescription
daysint1Number of days of heartbeats to return
Example Request
curl -H "X-API-Key: pp_..." {{ site_url }}/api/monitors/1/heartbeats/?days=7
Example Response
[
  {
    "status": "UP",
    "status_code": 200,
    "error": null,
    "response_time_ms": 145.23,
    "body_size": 12540,
    "checked_at": "2026-07-30T12:00:00Z"
  },
  {
    "status": "DOWN",
    "status_code": null,
    "error": "Connection timeout",
    "response_time_ms": null,
    "body_size": null,
    "checked_at": "2026-07-30T11:55:00Z"
  }
]
Response Fields
FieldTypeDescription
statusstringUP, DOWN, or DEGRADED
status_codeintHTTP status code (null on failure)
errorstringError message if check failed
response_time_msfloatResponse time in milliseconds
body_sizeintResponse body size in bytes
checked_atdatetimeCheck timestamp (ISO 8601)
Incidents GET

Returns all incidents for a monitor. Ordered by most recent first.

GET /api/monitors/<id>/incidents/
Example Request
curl -H "X-API-Key: pp_..." {{ site_url }}/api/monitors/1/incidents/
Example Response
[
  {
    "id": 1,
    "opened_at": "2026-07-25T07:58:45Z",
    "closed_at": "2026-07-25T08:28:54Z",
    "reason": "Resolved"
  },
  {
    "id": 2,
    "opened_at": "2026-07-25T15:11:56Z",
    "closed_at": null,
    "reason": "Resolved"
  }
]
Response Fields
FieldTypeDescription
idintUnique incident ID
opened_atdatetimeWhen the incident started (ISO 8601)
closed_atdatetimeWhen it resolved, or null if ongoing
reasonstringResolution reason
Monitor Stats GET

Returns aggregate statistics for a monitor.

GET /api/monitors/<id>/stats/
Example Request
curl -H "X-API-Key: pp_..." {{ site_url }}/api/monitors/1/stats/
Example Response
{
  "total_checks": 12540,
  "up_checks": 12480,
  "uptime_pct": 99.52,
  "current_status": "UP",
  "is_active": true
}
Response Fields
FieldTypeDescription
total_checksintTotal checks performed
up_checksintNumber of successful (UP) checks
uptime_pctfloatUptime percentage (all-time)
current_statusstringCurrent monitor status
is_activeboolWhether monitoring is active
