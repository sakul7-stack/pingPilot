API Documentation

Authenticate by passing your API key via the X-API-Key header.

List Monitors
# Returns all monitors for your account
curl -H "X-API-Key: pp_..." https://127.0.0.1:8000/api/monitors/
Monitor Details
# Replace <id> with the monitor ID from the list above
curl -H "X-API-Key: pp_..." https://127.0.0.1:8000/api/monitors/<id>/
Heartbeat Log
# Last 24 hours by default. Use ?days=N to change.
curl -H "X-API-Key: pp_..." https://127.0.0.1:8000/api/monitors/<id>/heartbeats/

# Example: last 7 days
curl -H "X-API-Key: pp_..." https://127.0.0.1:8000/api/monitors/<id>/heartbeats/?days=7
Incidents
# Returns all incidents for a monitor
curl -H "X-API-Key: pp_..." https://127.0.0.1:8000/api/monitors/<id>/incidents/
Monitor Stats
# Returns uptime, total checks, current status
curl -H "X-API-Key: pp_..." https://127.0.0.1:8000/api/monitors/<id>/stats/
